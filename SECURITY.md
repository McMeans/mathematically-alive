# Security Policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](../../security/advisories/new).

I'll reply within a week. This is a personal project, so there's no bug bounty.

## Scope

- The site and the code in this repository.
- Out of scope: CollegeFootballData's API and data, and third-party dependencies
  (report those upstream; Dependabot covers known CVEs).

## Supported versions

Only the latest `main` (the deployed site) gets fixes.
